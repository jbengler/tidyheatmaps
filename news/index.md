# Changelog

## tidyheatmaps (development version)

## tidyheatmaps 0.2.1

CRAN release: 2024-02-29

- Minor adjustments for CRAN submission.

## tidyheatmaps 0.2.0

- [`tidy_heatmap()`](https://jbengler.github.io/tidyheatmaps/reference/tidyheatmap.md)
  was renamed to
  [`tidyheatmap()`](https://jbengler.github.io/tidyheatmaps/reference/tidyheatmap.md).
  [`tidy_heatmap()`](https://jbengler.github.io/tidyheatmaps/reference/tidyheatmap.md)
  still works, but will be deprecated in the future.

## tidyheatmaps 0.1.0

- Initial release. tidyheatmaps simplifies the generation of
  publication-ready heatmaps from tidy data. By offering an interface to
  the powerful [pheatmap](https://github.com/raivokolde/pheatmap)
  package, it allows for the effortless creation of intricate heatmaps
  with minimal code.
